# Operating Systems

This is a collection of the Labs required by the course By Professor Dalila Megherbi in the Fall of 2023 at UMass Lowell.

- [Lab 1](lab1)
  - Purpose: To create a program that creates multiple processes.
- [Lab 2](lab2)
  - Purpose: To create a program that implements a single provider that services multiple buyers.
- [Lab 3](lab2)
  - Purpose: To create a program that implements malloc and free using threads and semaphores.
